# ひだまり個別教室 LP(ポートフォリオ用・架空サイト)

小学生向け個別指導塾の「無料体験申込」を促すLPです。**架空のサイト**で、フォームは送信されません。

## 見かた
`index.html` をブラウザで開くだけ。ビルド不要。

## フォルダ構成
```
index.html        … 構造(HTML)
css/style.css     … 見た目(トークン→共通→各セクション→フッター)
js/main.js        … FAQ開閉 / フォーム入力チェック(ダミー)
images/           … 写真2枚(fv.jpg, teacher.jpg)・保護者アイコンSVG3枚
```

## 設計の方針
- **モバイルファースト**:スマホ用を基本に書き、768px以上でPCレイアウト(2カラム等)を上書き
- **デザイントークン**:色・文字サイズ・余白は `:root` のCSS変数に集約
- **色の役割を固定**:ブランド青=見出し/アクセント、オレンジ=CTAと必須バッジのみ、黄マーカー=強調のみ
- **命名**:BEM風(`.block__element--modifier`)
- **アクセシビリティ**:見出し階層、label/for、aria-expanded、aria-invalid、alt
- **JSがなくても読める**:FAQは全展開で書き、JSで最初の2件以外を閉じる
- `noindex`:架空サイトのため検索に載せない
