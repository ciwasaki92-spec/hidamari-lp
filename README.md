# ひだまり個別教室 LP(ポートフォリオ用・架空サイト)

小学生向け個別指導塾の「無料体験申込」を促すLPです。**架空のサイト**で、フォームは送信されません。

## 見かた
`index.html` をブラウザで開くだけ。ビルド不要。

## フォルダ構成
```
index.html        … 構造(HTML)
css/style.css     … 見た目(トークン→共通→各セクション→フッター)
js/main.js        … ハンバーガーメニュー / FAQ開閉 / フォーム入力チェック(ダミー)
images/           … 写真2枚(fv.jpg, teacher.jpg)・イラスト(worry, closing, reason-teacher, flow-1〜4)・保護者アイコン3枚
```

## 設計の方針
- **モバイルファースト**:スマホ用を基本に書き、768px以上でPCレイアウト(2カラム等)を上書き
- **デザイントークン**:色・文字サイズ・余白は `:root` のCSS変数に集約
- **色の役割を固定**:ブランド青=見出し/アクセント、オレンジ=CTAと必須バッジのみ、黄=筆の線と強調のみ、濃紺=REPORTと申込フォームのみ
- **形に意味を持たせる**:番号は順番のある内容(入塾の流れ)だけ、箱は「選ぶもの」「書類」だけ、吹き出しは保護者の声だけ
- **命名**:BEM風(`.block__element--modifier`)
- **アクセシビリティ**:WCAG 2.1 AAを基準に確認(コントラスト、キーボード操作、メニュー表示中の`inert`、本文へスキップ、アニメーションは3回で停止、動きを減らす設定に対応)
- **日本語の改行**:BudouXで文節を判定して`<wbr>`を入れ、`word-break: keep-all`で文節単位に改行(Safariでも有効)
- **JSがなくても読める**:FAQは全展開で書き、JSで最初の2件以外を閉じる
- `noindex`:架空サイトのため検索に載せない

## 素材クレジット(要記入)
- FV写真:Adobe Stock(ライセンス取得済みの画像を使用)
- 先生写真:写真AC AIラボで制作者本人が生成(AI生成画像)
- イラスト(お悩み・先生・入塾の流れ・保護者アイコン):(入手先を記入)
- フォント:Noto Sans JP、Klee One(Google Fonts)
- 地図:Googleマップの埋め込み(川口駅周辺のイメージ)
